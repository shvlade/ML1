# Сбор и подготовка данных

> Учебные Jupyter-блокноты: работа с Pandas, HTTP-запросами и парсингом HTML через BeautifulSoup.

**Стек:** Python · Pandas · BeautifulSoup · Requests · Jupyter

## Содержание

Четыре блокнота для загрузки и подготовки данных. `Машлаба2.ipynb` содержит запросы HTTP и парсинг HTML через BeautifulSoup; остальные блокноты — упражнения с Pandas и интерактивными виджетами.

## Работа

Откройте `.ipynb` в JupyterLab или Google Colab. Установите нужные для выбранных ячеек библиотеки: `pandas`, `requests`, `beautifulsoup4`, `html5lib`, `ipywidgets`. URL и пути к входным данным указаны в ячейках; доступность внешних источников проверяется отдельно.

Это подготовка данных и учебные эксперименты, а не готовый сервис машинного обучения.
